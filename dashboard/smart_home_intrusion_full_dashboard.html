Endpoints
POST/login
Authenticate with username and password. Returns success or 401.
{"username": "admin", "password": "1234"} → {"status": "success"}
POST/detect
Submit sensor readings. Runs detector.py logic. Saves event if intrusion detected.
{"pir": 1, "distance": 9, "ldr": 680, "touch": 0} → {"intrusion": true, "message": "Motion + proximity alert"}
GET/api/events
Returns all stored events from events.json sorted by timestamp descending.
[{"timestamp":"2026-04-15T22:14:07","intrusion":true,"message":"...","pir":1,"distance":9}]
GET/api/network/latest
Returns the latest network monitoring event collected from the host.
{"source":"Network Monitor","event_class":"network","message":"New network connection ..."}
